# Pandula's Portfolio

This is my personal portfolio website built using **React** and **Vite**. It features a modern, dynamic design with smooth animations and responsive layouts that showcase my education, work experience, projects, and contact information.

## Features

- **Responsive Design:** Optimized for all screen sizes.
- **Smooth Animations:** Uses CSS animations and Intersection Observers for engaging fade-in effects.
- **Modular Components:** Clean and maintainable code structure.

## Technologies Used

- **React:** UI library for building interactive components.
- **Vite:** frontend tooling for fast development.
- **CSS3:** For styling, animations, and responsive layouts.
- **GitHub Pages:** For deployment of the portfolio.

## Available Scripts

- **`npm run dev`**  
  Starts the development server.

- **`npm run deploy`**  
  Deploys the production build to GitHub Pages.
